## 场景快速识别

```
涉及数字/ROI/预算？    → 财务建模 + 竞争动态推演
提到竞品/竞争格局？    → 竞品情报 + 竞争动态推演
问用户是谁/需求？      → 用户洞察 + 用户洞察深度方法
问怎么上市/进入市场？  → GTM策略 + 财务测算
涉及渠道/KA/定价？     → 渠道管理 + 定价策略 + 用户洞察深度
多维度混合？           → 全部模块
```

## 核心参数速查

```
财务基准：毛利率≥30%，净贡献率≥20%

渠道毛利：
电商 30-42% | DTC 40-52% | 线下 22-32% | 代理 15-25%

市场增速：
欧洲 10-15% | 东南亚 20-30% | 拉美 15-25% | 日本 3-6%

竞争：
成熟品类：头部主导60%+，新进入需差异化
成长品类：2-3年格局可能洗牌，渠道速度是关键
高端品类：品牌壁垒高，内容营销影响大
```

## 深度分析话术急救包

```
质疑："这个假设的依据是什么？"
      "请按保守情景重算，这个数字是否过于乐观？"

深入："用户不是整体，请分层分析。"
      "请结合外部市场和竞品动态来分析。"

极致："识别ROI最高的杠杆点。"
      "哪个不做其他全部白做？"
      "请提供三个版本的财务测算。"

收敛："如果只能选一个方案、只做三件事，是什么？"
      "真正的根因是什么？"
```

## 分析质量自检

```
□ 现象背后，本质问题有没有被说出来？
□ 核心假设有没有被列出并追问？
□ 数据有没有三个来源以上？
□ 用户有没有被分层？
□ 财务结论有没有三版本测算？
□ 方案有没有经过竞品反应推演？
□ 执行路径具体到可以行动了吗？
□ 有没有说清楚12个月后的目标？
□ 有没有说清楚"不做哪件事其他全部白做"？
□ 方案的失效条件和边界在哪？
```
