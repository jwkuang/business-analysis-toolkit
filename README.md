## 场景快速识别

```
涉及数字/ROI/预算？    → 财务建模 + 竞争动态推演
提到竞品/竞争格局？    → 竞品情报 + 竞争动态推演
问用户是谁/需求？      → 用户洞察 + 用户洞察深度方法
问怎么上市/进入市场？  → GTM策略 + 财务测算
涉及渠道/KA/定价？     → 渠道管理 + 定价策略 + 用户洞察深度
多维度混合？           → 全部模块
```

## 分析工作流地图

```
拿到业务场景后，按以下路径推进：

【第一步】问题分类
  → 用6问判断：财务决策 / 竞争策略 / 用户洞察 / GTM / 渠道运营 / 综合
  → 工具：《战略分析主 toolkit》第一部分

【第二步】澄清与假设
  → 现象背后真正的问题是什么？
  → 核心假设是什么？（必须列出）
  → 工具：《战略分析主 toolkit》第四部分追问话术

【第三步】数字基准获取
  → 这个场景需要哪些数据？（财务/竞争/用户/市场）
  → 检索真实数据，不依赖硬编码数字
  → 工具：《行业数据检索指南》

【第四步】模块化深度分析
  按场景类型调用对应模块（见上方"场景快速识别"）：
  财务决策 → 财务建模 + 竞争动态推演
  竞争策略 → 竞品情报 + 竞争动态推演
  用户洞察 → 用户洞察 + 用户洞察深度方法
  GTM     → GTM策略 + 财务测算 + 定价方法引用

【第五步】竞品动态推演（所有场景通用）
  → 竞品会注意到吗？会怎么反应？
  → 反应后方案还成立吗？有应对预案吗？
  → 工具：《竞争动态推演》

【第六步】建立追踪闭环
  → 成功指标（KBI）是什么？代理指标（Proxy KPI）？
  → FSP触发线在哪？复盘时间点？
  → 工具：《分析验证闭环系统》

【第七步】交付与可视化
  → 结论先行，量化支撑
  → 图表选择：趋势→折线 / 比较→柱状 / 比例→饼图
  → 工具：《可视化交付模板》

关键原则：
→ 分析过程中不断问："假设是什么？竞品会怎么反应？"
→ 财务结论必须三版本，压力测试不能跳过
→ 先有框架再有数据，不要用数据倒推框架
```

## 核心参数速查

> **所有数字必须检索获取，以下仅为方向指引，非基准值。**

```
财务基准：毛利率目标、毛利率≥[X]%、净贡献率≥[X]%
→ 检索：《行业数据检索指南》A类 + 上市公司年报

渠道毛利：
各渠道毛利差异极大，必须分渠道检索
→ 检索：《行业数据检索指南》A类

市场增速：
各区域/品类增速差异极大，必须分市场检索
→ 检索：《行业数据检索指南》B类

竞争：
成熟品类：头部品牌主导，[需检索实际集中度]
成长品类：2-3年格局可能洗牌，渠道速度是关键
高端品类：品牌壁垒高，内容营销影响大

引用原则：永远引用有来源的数字，不确定时用区间估算
```

## 深度分析话术急救包

```
质疑："这个假设的依据是什么？"
      "请按保守情景重算，这个数字是否过于乐观？"

深入："用户不是整体，请分层分析。"
      "请结合外部市场和竞品动态来分析。"

极致："识别ROI最高的杠杆点。"
      "哪个不做其他全部白做？"
      "请提供三个版本的财务测算。"

收敛："如果只能选一个方案、只做三件事，是什么？"
      "真正的根因是什么？"
```

## 分析质量自检

```
□ 现象背后，本质问题有没有被说出来？
□ 核心假设有没有被列出并追问？
□ 数据有没有三个来源以上？
□ 用户有没有被分层？
□ 财务结论有没有三版本测算？
□ 方案有没有经过竞品反应推演？
□ 执行路径具体到可以行动了吗？
□ 有没有说清楚12个月后的目标？
□ 有没有说清楚"不做哪件事其他全部白做"？
□ 方案的失效条件和边界在哪？
```
